## Rules shared by every M4 ticket

- **Nothing new.** M4 adds no feature, route, dependency or schema. A gap found while sweeping becomes a follow-up issue, not a change inside an M4 MR.
- **Docs-only MRs** (only `docs/**` or `*.md`, no human-owned file) skip the Cursor/Grok review under §10.2 and merge when CI is green. Any MR that touches `Makefile`, `scripts/` or code goes through the normal review.
- **Never:** `.gitlab-ci.yml` or a human-owned file (`docs/brief.md`, `requirements.md`, `threat-model.md`, `plan.md`, `operating-rules.md`); real orders; venue or Anthropic calls from tests; `ANTHROPIC_API_KEY` in a worker's env.
- **Tier 2 (M4-04, M4-07):** the D- entry in `docs/decisions.md` (numbered from the next free D- on main **and** in open MRs at push time; D-101 and D-102 are reserved here) and the "Awaiting human veto" row in `docs/status.md` ship in the same MR as the change. Spend stays within NFR-15 (≤ $50 total; status.md "Spend to date" is updated by the same MR).
- **Pre-push (§10.1 and §9):** self-review the diff against `docs/review.md`, `operating-rules.md`, the ACs and the auto-review checks; for code or script changes run `go test ./...`, `make cover`, `make e2e` and gitleaks locally and paste the measured numbers into the MR; one push per review round. Heavy local runs (`make e2e`, a live `equinox match`) one at a time per project.
- **Evidence.** Every AC lists how it was verified: a command, a test name, a URL that was curled, or a screenshot. Screenshots are real captures from the running app (no mock frames), attached to the MR unless small.
- **Dates and links.** The live URL is `https://equinox-o5hdimw5rq-uc.a.run.app` (`/health` is the health check, D-052). Times in docs are UTC with the timezone written out.
