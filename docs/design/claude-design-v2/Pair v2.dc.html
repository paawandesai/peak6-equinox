Pair detail: build notes

Templates: pair.html and history.html. The page is built around the terms diff, which is now the third block.

Components
  • verdict panel (.verdict) with the large badge
  • rule-layer tabs (details[name] group, no JS)
  • terms diff (table.terms): tbody per rule part, rows edged red for differs, blue for closed, gray for unknown
  • word-level <del>/<ins>
  • basis-risk back-links
  • freshness badge on each quote
VM fields (data already stored)
  • DiffRow.Part: maps each field to a rule part (subject and metric → criteria, threshold → strike, comparator → direction, deadline → timeframe, source → sources, edge rules → edge cases)
  • DiffRow.AHTML and BHTML: word diff rendered server-side
  • BasisComponent.Row: the diff field each component comes from
  • diff counts line
  • quote age
◆ Needs new data
  • Contribution column (prior, signed weight per row, total). The matcher stores no per-term weights.
  • Summary and Clarifications layers. Only the title and the full rules are stored.
  • LLM verifier rationale and run ID

Until these exist, hide the Contribution column and those two tabs.
