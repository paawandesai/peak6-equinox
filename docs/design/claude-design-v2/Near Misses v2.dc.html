Near misses: build notes

Template: near_misses.html. This is a “why not” view: each row opens with the failure, and rows are grouped by veto code. Rows with no veto are grouped under “fact did not close”.

Components
  • counter strip
  • group chips (in-page anchors)
  • veto badge (mono code)
  • row edge colour by group
  • “Not-a-match record” link
VM fields (data already stored)
  • Groups[]: rows grouped by first veto code (handler-side sort)
  • TermGap: numeric difference between A and B for threshold and deadline vetoes, from DiffRows
  • LogLink: the verdict log entry for the pair
  • fact-not-closed count (Total − VetoCount)
◆ Needs new data
  • Match score against the required score. The matcher stores the verdict and confidence, but not the pre-veto score a near miss would have had.
