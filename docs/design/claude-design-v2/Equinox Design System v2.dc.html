Equinox design system v2

There is one badge set and one freshness stamp, used on every page. Each state carries a word and a glyph, so colour is always a second channel. Pico.css supplies the type and form controls; these tokens sit on top of it.

The text stays the server's type string, so existing tests that match the chip text still pass. Markup: <span class="badge b-{{.Type}}"><span aria-hidden="true" class="g">≡</span>{{.Type}}</span>. The glyph comes from a VM helper (TypeGlyph), not from CSS content, so screen readers read only the word.

Confidence

Always the number plus a word: ▲ High (≥ 0.90, the route floor), ■ Medium (0.70–0.89), ▼ Low. The tick on the meter marks 0.90. Basis risk gets its own label and is never folded into confidence: 0.38 ■ moderate.
