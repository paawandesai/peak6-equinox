Route: build notes

Templates: the #route form in pair.html, route.html and route_result.html. The result reads like a cost report: outcome, then cost tiles, then the split, legs and alternatives.

Components
  • outcome badge, from the fixed set Routed / Partially routed / Not routed
  • cost tiles (dl.tiles)
  • split bar (.split > span[style=--w]; a CSP-safe alternative is in HANDOFF)
  • table.cost with the All-in column highlighted
  • chosen row in the alternatives table
  • sign-rule note
VM fields (data already stored)
  • Leg.Quoted: best price at the snapshot, from the round's quotes
  • Leg.SlippageBps, weighted total slippage
  • Leg.SharePct for the split bar
  • totals for cost, fees and basis (quantity × per-contract values)
  • Alt.GapBps
  • max quote age at decision time
◆ Needs new data

Nothing on this page. Every number is derived from the stored decision and the round's quotes.
