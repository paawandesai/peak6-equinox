Decision log: build notes

Template: log.html. Modelled on a TCA report. The existing kind <select> becomes chip links (?kind=), with a no-JS submit kept. When kind is routing, the table shows the order columns. Every other kind keeps When / Kind / About / Summary.

Components
  • filter chips (a.chip-filter[aria-current])
  • group-by chips
  • outliers panel
  • outcome and freshness badges
  • clamped summary inside details
VM fields (data already stored)
  • For routing entries, from the stored decision: pair, side, size, outcome, venues, average all-in, Δ to rank-2 alternative
  • max quote age (from the snapshot inputs, as on the decision page)
  • group=venue|staleness handler grouping
  • Outliers: the worst slippage and the oldest input among the listed rows
  • AboutTitle on verdict rows
◆ Needs new data
  • Label at decision time: the pair's relationship type when the order was routed. Decisions do not store it, and the pair may be re-matched later.
  • Group by label, which depends on it
